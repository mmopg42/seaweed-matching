## 주요 작업 항목

### 1. 일반카메라 폴더 접미사 사용 수정 (fix_normal_suffix_usage)

#### 1.1 전수조사 리포트 작성
- **문서**: `docs/spec/fix_normal_suffix_usage/normal_folder_suffix_usage_analysis.md`
- **내용**: 
  - `UseFolderSuffix` 설정을 사용하는 모든 코드 위치 전수조사
  - 7개 컴포넌트에서 문제점 발견 및 문서화
  - 현재 상태: 일부 코드는 설정을 확인하지만, 일부는 무조건 접미사 사용/무시

#### 1.2 발견된 주요 문제점
- **InitialScanner**: 접미사 필터링 없음
- **FileWatcherService**: 접미사 필터링 없음
- **GroupManager**: 접미사 우선 사용 (설정 무시)
- **FileGroup**: 접미사 우선 사용 (설정 무시)
- **StatisticsService**: 무조건 접미사 필터링
- **FileMatchingEngine**: UseFolderSuffix 미사용
- **FileGroupMatcherService**: UseFolderSuffix 미전달

#### 1.3 설계 문서 작성
- **요구사항** (`01_requirements.md`): 성공 기준 및 제약사항 정의
- **계획** (`03_plan.md`): 아키텍처 개요 및 컴포넌트 변경 사항
- **디자인** (`04_design.md`): 상세 설계 및 인터페이스 정의
- **작업 목록** (`05_tasks.md`): 13개 작업 항목 정의

#### 1.4 핵심 설계 결정
- **NormalFolderHelper** 신규 생성: 중앙화된 로직으로 중복 제거
- **경로 기반 라인 결정**: `UseFolderSuffix=false`일 때 `Normal1Path`/`Normal2Path`로 구분
- **접미사 우선순위**: `UseFolderSuffix=true`일 때 접미사 우선, 없으면 경로로 폴백

### 2. 로그 및 매칭 수정 (log_and_matching_fixing)

#### 2.1 문제 분석
- **문서**: `docs/spec/log_and_matching_fixing/01_requirements.md`
- **문제점**:
  1. 로그에서 Cam1~Cam6이 모두 "Camera"로 표시됨
  2. Line2 카메라(Cam4~6)가 제네릭 `DataType.Camera`로 뭉개짐
  3. 무로그 스킵 및 잘못된 그룹 배정 발생

#### 2.2 구현 계획 작성
- **문서**: `docs/spec/log_and_matching_fixing/03_plan.md`
- **목표**:
  - 로그에 카메라가 정확히 식별되도록 (Cam1~Cam6)
  - Line2 카메라들이 서로 경쟁하여 발생하는 문제 방지
  - 후보 탈락/스킵 사유를 UI 로그로 설명

#### 2.3 설계 결정
- **설정 공유 전제**: Cam4~6는 Line2의 Cam1~3이며 설정을 공유
- **표시/로그**: Line2일 때 Cam4~6로 표기
- **매칭 조회**: Cam4~6를 Cam1~3으로 정규화하여 조회

### 3. 일반카메라 폴더 이미지 지연 확인 로직 조사

#### 3.1 조사 리포트 작성
- **문서**: `docs/investigation/normal_folder_image_delay_check_logic.md`
- **목적**: 일반카메라 폴더 생성 후 20-40초 지연으로 이미지 파일이 생성되는 상황에서 재확인 로직 존재 여부 확인

#### 3.2 조사 결과
- **결론**: 이미지 파일이 없는 Normal 폴더는 `_knownFiles`에 추가하지 않도록 수정됨
- **해결 방법**: 폴더만 생성되고 이미지 파일이 없으면 `_knownFiles`에 추가하지 않아 폴링에서 계속 확인 가능

#### 3.3 구현된 로직
- `FileWatcherService.HandleEvent`: 이미지 파일이 있을 때만 `_knownFiles`에 추가
- `FileWatcherService.PerformSilentScan`: 초기 스캔 시에도 동일 로직 적용
- 폴링(2초마다)에서 이미지 파일이 없는 폴더를 계속 감지하여 이미지 생성 시 처리

#### 4.1 계획 문서 작성
