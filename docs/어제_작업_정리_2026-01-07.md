### 2. 파일 이동 로직 문제 분석

#### 2.1 이동 후 소스 파일 잔존 문제
- **문서**: `docs/trouble/move_leaves_source_after_move.md`
- **문제 현상**: 이동 작업 후 소스 파일/폴더가 그대로 남아있음
- **원인 분석**:
  - `File.Delete` 실패 시 예외 처리 부족
  - 파일이 다른 프로세스에 의해 잠겨있을 때 삭제 실패
  - 권한 문제로 삭제 실패
  - 다른 드라이브 간 이동 시 `Directory.Move` 실패
- **개선 방안**:
  - 삭제 실패 시 예외 발생 및 재시도 로직
  - 파일 잠금 확인 로직 추가
  - 롤백 로직 개선

#### 2.2 일반 카메라 이동 로직 문제
- **문서**: `docs/trouble/normal_camera_move_logic_issue.md`
- **문제 현상**: 일반 카메라 폴더 이동 시 원본 폴더명이 목적지 경로에 포함되지 않음
- **현재 동작**:
  - `MoveSchema`: 원본 폴더명 누락 → 여러 그룹이 같은 폴더로 이동하여 충돌
  - `QuarantineSchema`: 원본 폴더명 포함 (정상)
- **수정 방안**:
  - `MoveSchema`에서도 `folderName` 추출 및 경로 포함
  - `BuildPath` 메서드에서 `folderName` 파라미터 사용
