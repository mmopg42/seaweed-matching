# ChronoView 배포 가이드

## 개요

ChronoView는 .NET 10.0 WPF 애플리케이션입니다. 여러 배포 방식을 지원하며, 사용 환경에 따라 적절한 방식을 선택할 수 있습니다.

## 배포 옵션 비교

### 1. Self-Contained 단일 실행 파일 (권장)
- **장점**: 
  - 단일 .exe 파일로 배포 가능
  - .NET 런타임 포함 (사용자 PC에 .NET 설치 불필요)
  - 배포가 가장 간단
- **단점**: 
  - 파일 크기가 큼 (약 100-150MB)
  - 빌드 시간이 다소 길 수 있음
- **용도**: 일반 사용자 배포, 오프라인 환경

### 2. Self-Contained 폴더 배포
- **장점**: 
  - 단일 실행 파일보다 빌드 시간이 빠름
  - .NET 런타임 포함
- **단점**: 
  - 여러 파일로 구성됨
  - 압축 필요
- **용도**: 내부 배포, 설치 프로그램과 함께 사용

### 3. Framework-Dependent 배포
- **장점**: 
  - 파일 크기가 작음 (약 5-10MB)
  - 빌드 시간이 빠름
- **단점**: 
  - 사용자 PC에 .NET 10.0 런타임 설치 필요
- **용도**: .NET 런타임이 이미 설치된 환경

## 배포 방법

### 방법 1: Self-Contained 단일 실행 파일 (권장)

#### 1.1 프로젝트 파일 설정

`ChronoView.csproj`에 다음 속성을 추가합니다:

```xml
<PropertyGroup>
  <PublishSingleFile>true</PublishSingleFile>
  <SelfContained>true</SelfContained>
  <RuntimeIdentifier>win-x64</RuntimeIdentifier>
  <IncludeNativeLibrariesForSelfExtract>true</IncludeNativeLibrariesForSelfExtract>
  <PublishReadyToRun>true</PublishReadyToRun>
  <PublishTrimmed>false</PublishTrimmed> <!-- WPF는 Trimmed 빌드 미지원 -->
</PropertyGroup>
```

#### 1.2 배포 명령어

```powershell
# Release 모드로 단일 실행 파일 생성
dotnet publish ChronoView/ChronoView.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish/single-file

# 또는 win-x86 (32비트) 버전
dotnet publish ChronoView/ChronoView.csproj -c Release -r win-x86 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish/single-file-x86
```

#### 1.3 결과물
- `publish/single-file/ChronoView.exe` (단일 실행 파일)

### 방법 2: Self-Contained 폴더 배포

#### 2.1 배포 명령어

```powershell
# Release 모드로 폴더 배포
dotnet publish ChronoView/ChronoView.csproj -c Release -r win-x64 --self-contained true -o publish/folder

# 또는 win-x86 (32비트) 버전
dotnet publish ChronoView/ChronoView.csproj -c Release -r win-x86 --self-contained true -o publish/folder-x86
```

#### 2.2 결과물
- `publish/folder/` 폴더 전체 (실행 파일 + 런타임 + 의존성)

### 방법 3: Framework-Dependent 배포

#### 3.1 배포 명령어

```powershell
# Framework-dependent 배포 (작은 크기)
dotnet publish ChronoView/ChronoView.csproj -c Release -r win-x64 --self-contained false -o publish/framework-dependent
```

#### 3.2 결과물
- `publish/framework-dependent/` 폴더 (애플리케이션 파일만)
- 사용자는 별도로 .NET 10.0 런타임 설치 필요

### 방법 4: 설치 프로그램 생성 (Inno Setup)

#### 4.1 Inno Setup 스크립트 예제

`deployment/ChronoView.iss` 파일 생성:


#### 4.2 설치 프로그램 빌드

2. `ChronoView.iss` 파일 열기
3. Build > Compile 실행

## 배포 스크립트

### 배포 자동화 스크립트 (`deployment/publish.ps1`)

```powershell
# 배포 스크립트
param(
    [Parameter(Mandatory=$false)]
    [ValidateSet("single-file", "folder", "framework-dependent", "all")]
    [string]$Mode = "single-file",
    
    [Parameter(Mandatory=$false)]
    [ValidateSet("win-x64", "win-x86")]
    [string]$Runtime = "win-x64"
)

$ErrorActionPreference = "Stop"

Write-Host "=== ChronoView 배포 시작 ===" -ForegroundColor Green

# 프로젝트 경로
$projectPath = "ChronoView\ChronoView.csproj"
$publishBasePath = "publish"

# Clean
Write-Host "기존 빌드 파일 정리 중..." -ForegroundColor Yellow
if (Test-Path $publishBasePath) {
    Remove-Item -Path $publishBasePath -Recurse -Force
}

function Publish-SingleFile {
    Write-Host "`n[단일 실행 파일 배포]" -ForegroundColor Cyan
    $outputPath = "$publishBasePath\single-file-$Runtime"
    
    dotnet publish $projectPath `
        -c Release `
        -r $Runtime `
        --self-contained true `
        -p:PublishSingleFile=true `
        -p:IncludeNativeLibrariesForSelfExtract=true `
        -p:PublishReadyToRun=true `
        -o $outputPath
    
    Write-Host "✓ 배포 완료: $outputPath\ChronoView.exe" -ForegroundColor Green
}

function Publish-Folder {
    Write-Host "`n[폴더 배포]" -ForegroundColor Cyan
    $outputPath = "$publishBasePath\folder-$Runtime"
    
    dotnet publish $projectPath `
        -c Release `
        -r $Runtime `
        --self-contained true `
        -o $outputPath
    
    Write-Host "✓ 배포 완료: $outputPath" -ForegroundColor Green
}

function Publish-FrameworkDependent {
    Write-Host "`n[Framework-Dependent 배포]" -ForegroundColor Cyan
    $outputPath = "$publishBasePath\framework-dependent-$Runtime"
    
    dotnet publish $projectPath `
        -c Release `
        -r $Runtime `
        --self-contained false `
        -o $outputPath
    
    Write-Host "✓ 배포 완료: $outputPath" -ForegroundColor Green
    Write-Host "⚠ 사용자는 .NET 10.0 런타임을 별도로 설치해야 합니다." -ForegroundColor Yellow
}

# 배포 실행
switch ($Mode) {
    "single-file" { Publish-SingleFile }
    "folder" { Publish-Folder }
    "framework-dependent" { Publish-FrameworkDependent }
    "all" {
        Publish-SingleFile
        Publish-Folder
        Publish-FrameworkDependent
    }
}

Write-Host "`n=== 배포 완료 ===" -ForegroundColor Green
```

### 사용 예시

```powershell
# 단일 실행 파일만 배포
.\deployment\publish.ps1 -Mode single-file -Runtime win-x64

# 모든 방식으로 배포
.\deployment\publish.ps1 -Mode all -Runtime win-x64

# 32비트 버전 배포
.\deployment\publish.ps1 -Mode single-file -Runtime win-x86
```

## 배포 체크리스트

### 배포 전 확인사항

- [ ] `app_icon.ico` 파일이 프로젝트에 포함되어 있는지 확인
- [ ] 버전 정보가 올바르게 설정되어 있는지 확인
- [ ] Release 모드로 빌드 테스트
- [ ] 의존성 패키지 버전 확인
- [ ] 리소스 파일들이 올바르게 포함되는지 확인

### 배포 후 테스트

- [ ] 깨끗한 Windows PC에서 실행 테스트
- [ ] .NET 런타임 없이 실행 가능한지 확인 (Self-Contained)
- [ ] 모든 기능이 정상 작동하는지 확인
- [ ] 파일 경로에 한글이나 특수문자가 있어도 정상 작동하는지 확인

## 파일 크기 예상

- **Self-Contained 단일 실행 파일**: 약 100-150MB
- **Self-Contained 폴더**: 약 100-150MB (압축 시 약 50-70MB)
- **Framework-Dependent**: 약 5-10MB

## 추가 고려사항

### 코드 서명 (선택사항)

배포 시 코드 서명을 추가하면 Windows Defender 경고를 줄일 수 있습니다:

```powershell
# 코드 서명 인증서가 있는 경우
signtool sign /f certificate.pfx /p password /t http://timestamp.digicert.com publish/single-file/ChronoView.exe
```

### 버전 정보 설정

`ChronoView.csproj`에 버전 정보 추가:

```xml
<PropertyGroup>
  <Version>1.0.0</Version>
  <AssemblyVersion>1.0.0.0</AssemblyVersion>
  <FileVersion>1.0.0.0</FileVersion>
  <Product>ChronoView</Product>
  <Company>Your Company</Company>
  <Copyright>Copyright © 2026</Copyright>
</PropertyGroup>
```

### 아이콘 설정

`ChronoView.csproj`에 아이콘 추가:

```xml
<PropertyGroup>
  <ApplicationIcon>app_icon.ico</ApplicationIcon>
</PropertyGroup>

<ItemGroup>
  <None Include="app_icon.ico">
    <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
  </None>
</ItemGroup>
```

## 문제 해결

### 문제: "파일이 너무 큽니다" 경고
- 해결: `PublishTrimmed`를 `false`로 설정 (WPF는 Trimmed 빌드 미지원)

### 문제: 실행 시 DLL을 찾을 수 없음
- 해결: Self-Contained 배포 사용 또는 `IncludeNativeLibrariesForSelfExtract=true` 설정

### 문제: 시작 속도가 느림
- 해결: `PublishReadyToRun=true` 설정으로 시작 시간 단축
