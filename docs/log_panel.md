# log_panel.py 간략 문서

## 개요
로그 메시지를 표시하는 패널 위젯입니다.

**크기**: 2KB (80 라인)

## LogPanel 클래스

### 속성
- `log_box`: QTextEdit (읽기 전용)
- `btn_detail`: 상세 로그 버튼
- `btn_clear`: 로그 지우기 버튼

### 메서드
- `append(message)`: 로그 메시지 추가
- `clear()`: 로그 지우기
- `open_detail_dialog()`: 상세 로그 다이얼로그 열기

### UI 구성
```
┌─────────────────────────┐
│ [상세 로그 열기] [지우기]  │
├─────────────────────────┤
│ 로그 메시지...           │
│ ...                     │
└─────────────────────────┘
```

### 스타일
- 폰트: Consolas (고정폭)
- 배경색: #f0f0f0
- 최소 높이: 200px
- 최대 높이: 300px
