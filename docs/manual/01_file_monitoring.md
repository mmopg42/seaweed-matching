# 파일 모니터링

## 개요
ChronoView는 지정된 여러 폴더를 실시간으로 감시하여 새로운 파일이 생성되면 자동으로 감지하고 처리합니다.

## 모니터링 대상

### 카메라 파일
- **일반 카메라 (Normal)**: 폴더 단위로 이미지 그룹 저장
  - Line 1: Normal1 폴더
  - Line 2: Normal2 폴더
- **개별 카메라**: 파일 단위로 이미지 저장
  - Camera 1~6: 각각 독립적인 폴더

### NIR 파일
- **NIR 1**: Line 1용 NIR 스펙트럼 데이터 (.spc, .txt)
- **NIR 2**: Line 2용 NIR 스펙트럼 데이터

## 주요 기능

### 실시간 감시
- 파일 생성 즉시 감지
- 폴더 생성 감지 (Normal 폴더)
- 파일 변경 감지 (선택적)

### 우선순위 처리
- 이벤트 우선순위에 따라 처리 순서 결정
- 중요한 파일 먼저 처리

### 초기 스캔
- 모니터링 시작 시 기존 파일 자동 스캔
- 이미 존재하는 파일들도 그룹화

### 타임스탬프 캐싱
- 폴더별 마지막 처리 시간 기록
- 중복 처리 방지
- 성능 최적화

## 사용 방법

1. **설정에서 경로 지정**
   - 각 카메라 폴더 경로 입력
   - NIR 폴더 경로 입력

2. **모니터링 시작**
   - "시작" 버튼 클릭
   - 초기 스캔 자동 실행
   - 실시간 감시 시작

3. **모니터링 중지**
   - "중지" 버튼 클릭
   - 진행 중인 작업 완료 후 중지

## 설정 옵션

- **폴더 타임스탬프 캐시 TTL** (`FolderTimestampCacheTTL`): 캐시 유효 시간 (초)
- **병렬 처리 활성화** (`EnableParallelProcessing`): 파일 이벤트 병렬 처리 여부
- **최대 이벤트 처리 워커** (`MaxEventProcessingWorkers`): 동시 처리 가능한 파일 이벤트 수
- **폴링 활성화** (`EnablePolling`): 파일 시스템 폴링 모드 사용 여부
- **폴링 간격** (`PollingIntervalMs`): 폴링 간격 (밀리초)

## 로그 확인

모니터링 상태는 메인 화면 하단의 로그 패널에서 실시간으로 확인할 수 있습니다:
- 파일 감지 로그
- 그룹 생성 로그
- 오류 로그
