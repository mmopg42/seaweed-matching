# 외부 프로그램 연동

## 개요
ChronoView는 카메라 및 NIR 관련 외부 프로그램을 자동으로 실행하고 관리할 수 있습니다.

## 지원 프로그램

### 일반 카메라 프로그램 (General Camera)
- 범용 카메라 제어 소프트웨어
- 수동 시작/활성화
- 상태 모니터링
- 프로세스 종료 기능

### NIR 카메라 프로그램
- NIR 전용 카메라 소프트웨어
- Line 1용 NIR 카메라
- 수동 연동

### NIR2 카메라 프로그램
- Line 2용 NIR 카메라
- 독립적인 제어
- 동시 실행 가능

## 주요 기능

### 프로그램 실행 및 활성화
- 설정된 경로의 프로그램 실행
- 이미 실행 중인 경우 창 활성화
- 프로세스 ID 추적
- 상태 변경 이벤트 발생

### 프로세스 관리
- 실행 중인 프로그램 상태 확인
- 프로세스 종료 모니터링
- 프로세스 종료 기능 (Kill)
- 상태 동기화 (CheckStatusAsync)

## 설정 방법

### 프로그램 경로 설정
1. 설정 화면 열기
2. "외부 프로그램" 섹션
3. 각 프로그램 실행 파일 경로 지정
   - `GeneralCameraProgramPath`: 일반 카메라 프로그램
   - `NirCameraProgramPath`: NIR 카메라 프로그램
   - `Nir2CameraProgramPath`: NIR2 카메라 프로그램

## 사용 방법

### 수동 실행/활성화
1. 메인 화면 또는 설정 화면에서 프로그램 버튼 클릭
2. 프로그램이 실행되거나 이미 실행 중이면 창 활성화
3. 상태 표시 업데이트

### 수동 종료
1. 프로그램 버튼 다시 클릭 또는 종료 버튼 클릭
2. 프로세스 강제 종료 (Kill)
3. 상태 표시 업데이트

### 상태 확인
- 버튼 색상 또는 텍스트로 실행 상태 표시
- 실행 중: 활성화된 버튼 스타일
- 중지됨: 비활성화된 버튼 스타일

## NIR 필터링

ChronoView는 NIR 필터링 서비스를 포함하고 있으나, 현재 구현에서는 별도의 필터링 설정이 제공되지 않습니다. NIR 데이터는 파싱 후 자동으로 그래프로 변환됩니다.

## 문제 해결

### 프로그램이 시작되지 않음
- 실행 파일 경로 확인
- 파일 존재 여부 확인
- 실행 권한 확인
- 로그에서 오류 메시지 확인

### 프로그램이 응답하지 않음
- 작업 관리자에서 프로세스 확인
- ChronoView에서 종료 버튼 클릭 (강제 종료)
- 필요시 작업 관리자에서 수동 종료

### 프로그램이 자동으로 종료됨
- 프로세스 모니터링이 종료를 감지하여 상태 업데이트
- 프로그램 자체의 오류 또는 사용자가 직접 종료한 경우

## 주의사항

⚠️ **프로그램 호환성**
- 프로그램 실행 및 창 활성화 기능 제공
- 자동 시작/종료 기능은 제공되지 않음
- 수동 제어 방식

⚠️ **리소스 사용**
- 여러 프로그램 동시 실행 시 시스템 부하
- 메모리 및 CPU 사용량 모니터링
- 필요한 프로그램만 실행

⚠️ **보안**
- 신뢰할 수 있는 프로그램만 설정
- 실행 파일 경로 확인
