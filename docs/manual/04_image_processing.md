# 이미지 처리

## 개요
ChronoView는 카메라 이미지를 효율적으로 로딩하고 표시하기 위한 다양한 이미지 처리 기능을 제공합니다.

## 주요 기능

### 썸네일 생성
- ImageSharp 라이브러리 사용
- 원본 이미지에서 작은 썸네일 자동 생성
- 종횡비 유지하며 리사이즈 (ResizeMode.Max)
- JPEG 형식으로 인코딩 (설정 가능한 품질)
- 메인 화면에서 빠른 미리보기
- 메모리 효율적인 표시

### 이미지 캐싱
- LRU (Least Recently Used) 캐시 사용
- 설정 가능한 최대 캐시 크기 (MB 단위)
- 자주 사용하는 이미지 메모리에 유지
- 반복 로딩 방지로 성능 향상
- 썸네일 캐시와 메타데이터 캐시 분리

### 비동기 로딩
- Task.Run을 사용한 백그라운드 처리
- CPU 집약적 작업을 별도 스레드에서 실행
- UI 블로킹 없이 이미지 로딩
- SemaphoreSlim을 사용한 동시 처리 제한 (ProcessorCount * 2)
- 취소 토큰 지원

### 플레이스홀더
- 이미지 로딩 실패 시 회색 배경에 X 표시된 플레이스홀더 이미지 생성
- 파일 없음 또는 오류 상태 시각적 표시

## 지원 형식

- JPEG (.jpg, .jpeg)
- PNG (.png)
- BMP (.bmp)
- TIFF (.tif, .tiff)
- 기타 WPF 지원 형식

## 이미지 표시

### 메인 화면
- 각 그룹의 대표 썸네일
- 작은 크기로 빠른 로딩
- 그리드 형태로 정렬

### 상세 보기
- 큰 이미지 미리보기
- 확대/축소 가능
- 여러 이미지 슬라이드쇼

### 이미지 미리보기 창
- 전체 화면 이미지 보기
- 이전/다음 이미지 탐색
- 확대/축소/회전

## 성능 최적화

### 캐시 설정
- **최대 캐시 크기** (`MaxCacheSizeMB`): 메모리 사용량 제어 (MB 단위)
- **캐시 활성화** (`EnableCaching`): 캐싱 기능 사용 여부
- 캐시 정책: LRU 알고리즘
- 자동 정리: 캐시 크기 초과 시

### 동시 처리 제한
- SemaphoreSlim을 사용한 동시 처리 제한
- 기본값: Math.Max(4, ProcessorCount * 2)
- 스레드 풀 고갈 방지

### 썸네일 품질
- **썸네일 품질** (`ThumbnailQuality`): JPEG 인코딩 품질 (0-100)
- 품질과 파일 크기 균형

## 문제 해결

### 이미지가 표시되지 않음
- 파일 형식 확인
- 파일 손상 여부 확인
- 파일 접근 권한 확인

### 로딩이 느림
- 캐시 크기 증가
- 이미지 파일 크기 확인
- 디스크 속도 확인
