# ChronoView 사용자 매뉴얼

## 개요
ChronoView는 여러 카메라와 NIR(근적외선) 센서에서 생성된 파일들을 자동으로 그룹화하고 관리하는 모니터링 애플리케이션입니다.

## 주요 기능

1. **[파일 모니터링](01_file_monitoring.md)** - 여러 폴더를 실시간으로 감시하고 새 파일 감지
2. **[파일 그룹화](02_file_grouping.md)** - 타임스탬프 기반으로 관련 파일들을 자동 그룹화
3. **[NIR 데이터 처리](03_nir_processing.md)** - NIR 스펙트럼 데이터 파싱 및 그래프 생성
4. **[이미지 처리](04_image_processing.md)** - 이미지 로딩, 썸네일 생성, 캐싱
5. **[비정상 감지](05_abnormal_detection.md)** - 통계 분석을 통한 이상 데이터 자동 감지
6. **[파일 작업](06_file_operations.md)** - 파일 이동, 삭제, 경로 관리
7. **[통계 및 분석](07_statistics.md)** - 실시간 파일 카운트 및 매칭 통계
8. **[설정 관리](08_configuration.md)** - 애플리케이션 설정 및 워크플로우 구성
9. **[외부 프로그램 연동](09_program_launching.md)** - 카메라 프로그램 자동 실행
10. **[사용자 인터페이스](10_user_interface.md)** - 메인 화면, 설정 화면, 상세 보기

## 시작하기

1. 애플리케이션 실행
2. 설정 화면에서 모니터링할 폴더 경로 지정
3. 시작 버튼 클릭하여 모니터링 시작
4. 실시간으로 파일 그룹 확인

## 시스템 요구사항

- Windows 10 이상
- .NET 10.0
- 충분한 디스크 공간 (로그 및 캐시용)

## 지원

문제가 발생하면 로그 파일을 확인하세요:
- 위치: `%APPDATA%\ChronoView\Logs\`
- 날짜별 폴더에 저장됨
