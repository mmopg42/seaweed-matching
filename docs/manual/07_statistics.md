# 통계 및 분석

## 개요
ChronoView는 실시간으로 파일 카운트와 매칭 통계를 제공합니다.

## 파일 카운트 통계

### 실시간 모니터링
- 각 폴더의 파일 수 실시간 업데이트
- 100ms 간격으로 자동 갱신
- 변경 감지 시에만 UI 업데이트

### 카운트 항목
- **NIR 1**: Line 1 NIR 파일 수
- **NIR 2**: Line 2 NIR 파일 수
- **Normal 1**: Line 1 Normal 폴더 수
- **Normal 2**: Line 2 Normal 폴더 수
- **Camera 1~6**: 각 카메라 파일 수

### 표시 위치
- 메인 화면 상단 통계 패널
- 각 항목별 숫자 표시
- 마지막 업데이트 시간 표시

## 매칭 통계

### 통합 모드
전체 그룹에 대한 통계:
- **총 그룹 수**: 생성된 전체 그룹
- **NIR 포함**: NIR 데이터가 있는 그룹
- **NIR 없음**: NIR 데이터가 없는 그룹
- **실패**: 매칭 실패한 그룹

### 분리 모드
라인별 독립 통계:
- **Line 1 통계**: Line 1 그룹만
- **Line 2 통계**: Line 2 그룹만
- 각 라인별 NIR 매칭률

### 매칭률 계산
```
매칭률 = (NIR 포함 그룹 / 총 그룹) × 100%
```

## 성능 메트릭

### 시스템 성능
- **가동 시간**: 모니터링 시작 후 경과 시간
- **파일 카운트 업데이트 횟수**: 통계 갱신 빈도
- **통계 계산 횟수**: 매칭 통계 계산 빈도
- **비정상 조건 보고 수**: 감지된 이상 건수

### 모니터링 상태
- **모니터링 중**: 활성/비활성
- **마지막 업데이트**: 최근 통계 갱신 시간

## 통계 패널

### 위치
- 메인 화면 우측 또는 상단
- 접기/펼치기 가능
- 크기 조절 가능

### 표시 정보
- 실시간 파일 카운트
- 매칭 통계 요약
- 그래프 또는 차트 (선택적)

## 통계 내보내기

### 지원 형식
- CSV 파일
- JSON 파일
- 텍스트 보고서

### 내보내기 항목
- 파일 카운트 스냅샷
- 매칭 통계
- 성능 메트릭
- 타임스탬프

## 사용 방법

### 통계 보기
1. 메인 화면에서 통계 패널 확인
2. 실시간으로 자동 업데이트
3. 특정 항목 클릭하여 상세 정보

### 통계 새로고침
1. "새로고침" 버튼 클릭
2. 수동으로 통계 재계산
3. 모든 폴더 다시 스캔

### 통계 초기화
1. 설정 화면에서 "통계 초기화"
2. 모든 카운트 0으로 리셋
3. 새로운 모니터링 세션 시작

## 문제 해결

### 통계가 업데이트되지 않음
- 모니터링 상태 확인
- 폴더 접근 권한 확인
- 로그에서 오류 확인

### 카운트가 부정확함
- 수동 새로고침 실행
- 폴더 경로 설정 확인
- 파일 필터 설정 확인
