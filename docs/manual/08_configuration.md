# 설정 관리

## 개요
ChronoView의 모든 설정은 설정 화면에서 관리할 수 있습니다.

## 설정 파일 위치
- 경로: `%APPDATA%\ChronoView\config.json`
- JSON 형식
- 수동 편집 가능 (주의 필요)

## 주요 설정 항목

### 매칭 설정

#### 폴더 경로
- **NIR 1 경로**: Line 1 NIR 파일 폴더
- **NIR 2 경로**: Line 2 NIR 파일 폴더
- **Normal 1 경로**: Line 1 Normal 폴더
- **Normal 2 경로**: Line 2 Normal 폴더
- **Camera 1~6 경로**: 각 카메라 파일 폴더

#### 매칭 옵션
- **타임스탬프 허용 오차**: 파일 매칭 시간 범위 (초)
- **폴더 접미사 사용**: Normal 폴더 이름 검증
- **라인별 그룹 ID**: 라인별 독립 ID 사용

### 워크플로우 설정

#### 워크플로우 옵션
- **폴더 타임스탬프 캐시 TTL**: 캐시 유효 시간 (초, 기본: 300)
- **초기 스캔 활성화**: 시작 시 기존 파일 스캔
- **병렬 처리 활성화**: 동시 이벤트 처리 (기본: true)
- **최대 이벤트 처리 워커 수**: 병렬 처리 스레드 수 (기본: 3, 범위: 1-8)
- **폴링 활성화**: 네트워크 드라이브 감지 보장 (기본: true)
- **폴링 간격**: 폴링 주기 (밀리초, 기본: 200)
- **격리 폴더 경로**: 삭제 시 파일 이동 경로

#### 성능 옵션
- **파일 시스템 감시자 버퍼 크기**: 기본 65536
- **롤백 활성화**: 작업 실패 시 자동 롤백 (기본: true)

### 비정상 감지 설정

#### 감지 임계값
- **백분율 임계값**: 편차 허용 범위 (%)
- **윈도우 크기**: 통계 샘플 수
- **최소 샘플**: 감지 시작 샘플 수

#### 적응형 설정
- **연속 비정상 한계**: 재설정 트리거 횟수
- **자동 재설정**: 활성화/비활성화

### UI 설정

#### 표시 옵션
- **이미지 표시 너비/높이**: DataGrid의 이미지 크기 (픽셀)
- **NIR 표시 너비/높이**: NIR 그래프 표시 크기 (픽셀)
- **DataGrid 행 높이**: 행 높이 (픽셀, 기본: 100)
- **표시 글꼴 크기**: 레이블 글꼴 크기 (기본: 10.0)
- **툴팁 표시**: 마우스 오버 시 툴팁 (기본: true)
- **레거시 UI 모드**: 이전 UI 사용 (기본: false)

### 로깅 설정

#### 로그 보관
- **로그 보관 기간**: 일 단위 (기본: 30일)
- **자동 정리**: 오래된 로그 자동 삭제
- **로그 위치**: `%APPDATA%\ChronoView\Logs\{yyyyMMdd}\`

#### 로그 레벨
애플리케이션 코드에서 설정 (App.xaml.cs):
- **Debug**: 모든 상세 정보
- **Information**: 일반 정보 (기본)
- **Warning**: 경고만
- **Error**: 오류만

## 설정 화면 사용

### 설정 열기
1. 메인 화면에서 "설정" 버튼 클릭
2. 또는 메뉴에서 "설정" 선택
3. 설정 대화상자 표시

### 설정 변경
1. 원하는 항목 수정
2. "적용" 버튼 클릭
3. 변경사항 즉시 반영

### 설정 저장
1. "저장" 버튼 클릭
2. config.json 파일에 저장
3. 다음 실행 시 자동 로드

### 설정 취소
1. "취소" 버튼 클릭
2. 변경사항 무시
3. 이전 설정 유지

## 설정 백업 및 복원

### 백업
1. config.json 파일 복사
2. 안전한 위치에 저장
3. 날짜 포함 파일명 권장

### 복원
1. 백업 파일을 config.json으로 복사
2. 애플리케이션 재시작
3. 설정 자동 로드

## 기본 설정 복원

### 방법 1: 설정 화면
1. 설정 화면에서 "기본값 복원" 버튼
2. 확인 대화상자
3. 모든 설정 초기화

### 방법 2: 파일 삭제
1. 애플리케이션 종료
2. config.json 파일 삭제
3. 재시작 시 기본 설정 생성

## 문제 해결

### 설정이 저장되지 않음
- 파일 접근 권한 확인
- 디스크 공간 확인
- config.json 파일 잠금 확인

### 설정 파일 손상
- 백업에서 복원
- 또는 파일 삭제 후 재생성
- 로그에서 오류 확인

### 설정 적용 안 됨
- 애플리케이션 재시작
- 모니터링 재시작
- 설정 파일 형식 확인
