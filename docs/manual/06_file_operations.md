# 파일 작업

## 개요
ChronoView는 파일 그룹에 대한 다양한 작업을 지원합니다.

## 지원 작업

### 파일 이동
- 선택한 그룹의 모든 파일을 다른 위치로 이동
- 폴더 구조 유지 옵션
- 이동 후 원본 삭제

### 파일 삭제 (격리)
- 선택한 그룹의 파일을 격리 폴더(Quarantine)로 이동
- 영구 삭제가 아닌 안전한 격리
- 확인 대화상자 표시
- 격리된 파일은 수동으로 복구 가능

### 경로 관리
- 대상 경로 자동 생성
- 날짜별 폴더 구조 (yyyyMMdd)
- 라인별 폴더 구조 (Line1/Line2)

## 사용 방법

### 그룹 선택
1. 메인 화면에서 그룹 선택
2. 단일 선택 또는 다중 선택 (Ctrl/Shift 키)
3. 마우스 우클릭 또는 버튼 클릭

### 이동 작업
1. "이동" 버튼 클릭
2. 대상 폴더 선택
3. 옵션 설정:
   - 폴더 구조 유지
   - 덮어쓰기 여부
4. 확인 클릭

### 삭제 작업
1. "삭제" 버튼 클릭
2. 확인 대화상자에서 격리 경로 확인
3. 확인 클릭
4. 파일이 격리 폴더로 이동
5. 그룹 목록에서 제거

**격리 경로**: 설정에서 지정 (기본: `{BasePath}/Quarantine` 또는 `{BasePath}/Trash`)

## 작업 옵션

### 이동 옵션
- **폴더 구조 유지**: 원본 폴더 구조 그대로 복사
- **덮어쓰기**: 동일 파일 존재 시 덮어쓰기
- **로그 기록**: 작업 내역 로그 파일에 기록

### 삭제 옵션
- **격리 경로**: 파일이 이동될 격리 폴더 경로
- **확인 대화상자**: 삭제 전 확인 (권장)
- **로그 기록**: 삭제 내역 로그 파일에 기록

## 격리 폴더 구조

삭제된 파일은 다음 구조로 격리됩니다:
```
{격리경로}/
├── {yyyyMMdd}/          # 날짜 폴더
│   ├── Line1/           # 라인별 분리
│   │   ├── {샘플명}/
│   │   │   ├── 일반1/   # Normal 폴더
│   │   │   ├── nir1/    # NIR 파일
│   │   │   └── cam1/    # 카메라 파일
│   │   └── ...
│   └── Line2/
│       └── ...
```

## 안전 기능

### 확인 대화상자
- 중요한 작업 전 확인 요청
- 작업 취소 가능
- 영향받는 파일 수 표시

### 오류 처리
- 파일 접근 오류 시 건너뛰기
- 오류 로그 기록
- 부분 성공 시 결과 보고

### 롤백
- 이동 실패 시 자동 롤백 (선택적)
- 원본 파일 보존

## 로그 확인

모든 파일 작업은 로그에 기록됩니다:
- 작업 유형 (이동/삭제)
- 대상 파일 목록
- 성공/실패 여부
- 오류 메시지

## 주의사항

⚠️ **삭제는 격리 폴더로 이동**
- 영구 삭제가 아닌 격리 폴더로 이동
- 격리된 파일은 수동으로 복구 가능
- 격리 폴더 경로는 설정에서 지정
- 정기적으로 격리 폴더 정리 권장

⚠️ **이동 작업 시 디스크 공간 확인**
- 대상 드라이브에 충분한 공간 필요
- 공간 부족 시 작업 실패

⚠️ **동시 작업 제한**
- 한 번에 하나의 작업만 실행
- 작업 완료 후 다음 작업 가능

## 격리 파일 복구

격리된 파일을 복구하려면:
1. 격리 폴더로 이동 (설정에서 경로 확인)
2. 날짜 및 라인 폴더 탐색
3. 원하는 파일 찾기
4. 수동으로 원래 위치 또는 다른 위치로 복사
