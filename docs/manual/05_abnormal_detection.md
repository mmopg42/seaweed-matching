# 비정상 감지

## 개요
ChronoView는 통계 분석을 통해 비정상적인 데이터를 자동으로 감지하고 경고합니다.

## 감지 방법

### 이미지 크기 분석
- 이미지 너비/높이의 통계적 분석
- 중앙값(Median) 기반 기준선 설정
- 백분율 편차 계산
- 임계값 초과 시 비정상 판정

### 컨텍스트별 분석
- 라인별 독립적인 통계 (Line 1, Line 2)
- 카메라별 독립적인 통계 (Cam 1~6)
- 각 컨텍스트마다 별도의 히스토리 유지

### 적응형 재설정
- 연속 비정상 감지 시 자동 재설정
- 프로세스 변경 감지
- 새로운 기준선 설정

## 감지 유형

### 이미지 크기 이상
- 너비 또는 높이가 정상 범위를 벗어남
- 설정된 임계값 초과
- 예: 일반적으로 1920x1080인데 640x480 감지

### NIR 전용 그룹
- NIR 데이터만 있고 카메라 데이터 없음
- 매칭 실패 가능성
- 데이터 누락 의심

### 설정 옵션

### 감지 임계값
- **백분율 임계값** (`AbnormalPercentThreshold`): 편차 허용 범위 (기본: 12%)
- **윈도우 크기** (`AbnormalDetectionWindowSize`): 통계 계산에 사용할 샘플 수 (기본: 40)
- **최소 샘플**: 감지 시작 전 필요한 샘플 수 (기본: 5, 코드 내 상수)

### 적응형 재설정
- **연속 비정상 한계**: 재설정 트리거 횟수 (기본: 10)
- 한계 도달 시 히스토리 초기화
- 현재 데이터를 새로운 정상으로 간주

### 비정상 데이터 처리

### 클린 베이스라인 정책
- **비정상 샘플은 히스토리에 추가하지 않음**
- 정상 샘플만 통계 계산에 사용
- 히스토리 품질 유지

### 표시
- 메인 화면에서 비정상 그룹 강조 표시
- 빨간색 또는 경고 아이콘
- 상태 컬럼에 "Abnormal" 표시

### 로깅
- 비정상 감지 시 자동 로깅
- 편차 백분율 기록
- 컨텍스트 정보 포함

### 통계
- 비정상 그룹 카운트
- 감지 이력 저장
- 히스토리 파일: `%APPDATA%\ChronoView\abnormal_history.json`

## 사용 방법

1. **자동 감지**
   - 모니터링 시작 시 자동 활성화
   - 백그라운드에서 지속적으로 분석

2. **수동 재설정**
   - 설정 화면에서 히스토리 초기화
   - 새로운 프로세스 시작 시 권장

3. **임계값 조정**
   - 너무 많은 오탐지 시 임계값 증가
   - 감지 누락 시 임계값 감소

## 문제 해결

### 정상 데이터가 비정상으로 감지됨
- 임계값 증가
- 윈도우 크기 증가
- 히스토리 재설정

### 비정상 데이터가 감지되지 않음
- 임계값 감소
- 최소 샘플 수 확인
- 컨텍스트 설정 확인
