# NIR 데이터 처리

## 개요
ChronoView는 NIR(근적외선) 스펙트럼 데이터를 자동으로 파싱하고 시각화합니다.

## 지원 파일 형식

### TXT 파일
- 텍스트 기반 스펙트럼 데이터
- 파장-강도 쌍으로 구성
- CSV 형식도 지원

## 주요 기능

### 자동 파싱
- 파일 형식 자동 감지
- 스펙트럼 데이터 추출
- 파장 및 강도 값 읽기

### 그래프 생성
- ScottPlot 라이브러리를 사용한 스펙트럼 시각화
- PNG 이미지로 변환
- 썸네일 자동 생성
- 미니멀한 스타일 (프레임 없음, 그리드 숨김)

### 그래프 표시
- 파장 범위를 X축에 매핑
- 강도 값을 Y축에 표시
- 파란색 선 그래프 (#0078d4)
- 밝은 회색 배경 (#f5f5f5)

## NIR 데이터 표시

### 메인 화면
- 각 그룹에 NIR 썸네일 표시
- NIR 유무 아이콘 표시

### 상세 보기
- 큰 NIR 그래프 표시
- 파장-강도 데이터 확인
- 그래프 확대/축소

## 설정 옵션

- **NIR 1 경로** (`Nir1Path`): Line 1용 NIR 파일 폴더
- **NIR 2 경로** (`Nir2Path`): Line 2용 NIR 파일 폴더
- **NIR 썸네일 크기** (`NirThumbnailWidth`, `NirThumbnailHeight`): 생성되는 그래프 이미지 크기

## 문제 해결

### NIR 파일이 매칭되지 않음
- 타임스탬프 형식 확인
- DataSequenceSettings에서 NIR의 MinDelay/MaxDelay 설정 확인
- 파일 이름 규칙 확인

### 그래프가 표시되지 않음
- 파일 형식 확인 (.txt 또는 .csv)
- 파일 손상 여부 확인
- 로그에서 파싱 오류 확인
