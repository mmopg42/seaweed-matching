# 사용자 인터페이스

## 개요
ChronoView는 직관적이고 효율적인 사용자 인터페이스를 제공합니다.

## 메인 화면

### 레이아웃
```
┌─────────────────────────────────────────┐
│  [메뉴] [시작] [중지] [설정]  [통계]    │
├─────────────────────────────────────────┤
│  Line 1 그룹 목록                        │
│  ┌───┬───┬───┬───┐                      │
│  │ 1 │ 2 │ 3 │ 4 │                      │
│  └───┴───┴───┴───┘                      │
├─────────────────────────────────────────┤
│  Line 2 그룹 목록                        │
│  ┌───┬───┬───┬───┐                      │
│  │ 1 │ 2 │ 3 │ 4 │                      │
│  └───┴───┴───┴───┘                      │
├─────────────────────────────────────────┤
│  로그 패널                               │
│  [시간] [레벨] [메시지]                  │
└─────────────────────────────────────────┘
```

### 주요 구성 요소

#### 도구 모음
- **시작 버튼**: 모니터링 시작
- **중지 버튼**: 모니터링 중지
- **설정 버튼**: 설정 화면 열기
- **새로고침**: 화면 갱신

#### 그룹 목록
- **그리드 뷰**: 썸네일 그리드
- **리스트 뷰**: 상세 목록
- **필터**: 상태별 필터링
- **정렬**: 시간/ID/상태별 정렬

#### 통계 패널
- 실시간 파일 카운트
- 매칭 통계
- 성능 메트릭

#### 로그 패널
- 실시간 로그 표시
- 레벨별 색상 구분
- 필터링 및 검색

## 설정 화면

### 탭 구성
1. **Line 1**: Line 1 그룹 목록 및 샘플 이동 설정
2. **Line 2**: Line 2 그룹 목록 및 샘플 이동 설정
3. **통합**: 전체 그룹 목록 (Line 1 + Line 2)

### 주요 기능
- 각 탭별 샘플 이동 설정
  - **샘플명**: 이동할 샘플 이름
  - **NIR 이동**: 이동할 NIR 파일 개수 (비어있으면 전체)
  - **전체 데이터 이동**: 이동할 전체 데이터 개수 (비어있으면 전체)
- 설정 자동 저장 (500ms 디바운스)
- 실시간 유효성 검사

## 상세 보기 화면

### 그룹 상세 정보
- 그룹 ID 및 타임스탬프
- 포함된 모든 파일 목록
- 파일 경로 및 크기
- 상태 정보

### 이미지 미리보기
- 큰 이미지 표시
- 이전/다음 탐색
- 확대/축소
- 전체 화면

### NIR 그래프
- 스펙트럼 그래프 표시
- 파장-강도 데이터
- 확대/축소
- 데이터 내보내기

## 초기 설정 화면

ChronoView는 별도의 초기 설정 화면을 제공하지 않습니다. 첫 실행 시 기본 설정으로 시작하며, 설정 파일을 통해 경로 및 옵션을 구성할 수 있습니다.

## 스플래시 화면

ChronoView는 별도의 스플래시 화면을 제공하지 않습니다. 애플리케이션이 직접 메인 화면으로 시작됩니다.

## 키보드 단축키

현재 ChronoView는 명시적인 키보드 단축키를 제공하지 않습니다. 표준 Windows 단축키(Ctrl+C 복사 등)는 사용 가능합니다.

## 마우스 동작

### 그룹 목록
- **클릭**: 선택
- **더블클릭**: 상세 보기
- **우클릭**: 컨텍스트 메뉴
- **드래그**: 다중 선택

### 이미지
- **클릭**: 선택
- **더블클릭**: 전체 화면
- **휠**: 확대/축소
- **드래그**: 이동 (확대 시)

## 테마 및 스타일

### 표시 설정
- **이미지 표시 크기** (`DisplayImageWidth`, `DisplayImageHeight`): 메인 화면 썸네일 크기
- **NIR 표시 크기** (`NirThumbnailWidth`, `NirThumbnailHeight`): NIR 그래프 썸네일 크기
- **글꼴 크기** (`DisplayFontSize`): UI 글꼴 크기
- **데이터 그리드 행 높이** (`DataGridRowHeight`): 그룹 목록 행 높이

### 로그 패널
- 접기/펼치기 가능
- 높이 조절 가능
- 기본 높이: 200px

## 접근성

ChronoView는 표준 WPF 접근성 기능을 지원합니다.

## 언어

ChronoView의 사용자 인터페이스는 한국어로 제공됩니다.

## 문제 해결

### UI가 응답하지 않음
- 작업 완료 대기
- 로그 확인
- 애플리케이션 재시작

### 화면이 깨짐
- 해상도 확인
- 테마 변경
- 기본 설정 복원

### 느린 반응
- 그룹 수 확인
- 썸네일 크기 줄이기
- 캐시 정리
