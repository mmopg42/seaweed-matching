# 이동/삭제 경로 규칙

**작성일**: 2025-01-17  
**구현 위치**: `ChronoView/Core/FileOperations/FileGroupOperator.cs`

---

## 개요

이동(Move) 및 삭제(Quarantine) 작업 시 대상 경로에 날짜 폴더(`yyyyMMdd`)가 포함되어 있는지 자동으로 감지하고, 없을 경우 오늘 날짜를 자동으로 추가합니다. 이를 통해 사용자가 경로에 날짜를 포함할지 여부를 선택할 수 있으며, 일관된 폴더 구조를 유지할 수 있습니다.

---

## 경로 규칙

### 기본 원칙

1. **날짜 감지**: 대상 경로(`basePath`)에 **유효한 `yyyyMMdd` 형식의 날짜 폴더 세그먼트**가 포함되어 있는지 확인합니다.
2. **자동 삽입**: 날짜가 없으면 **오늘 날짜(`yyyyMMdd`)**를 자동으로 추가합니다.
3. **중복 방지**: 경로에 이미 유효한 날짜가 있으면 추가하지 않습니다.

### 날짜 감지 로직

- 경로의 각 세그먼트를 검사하여 8자리 숫자 문자열을 찾습니다.
- `^(19|20)\d{6}$` 패턴으로 빠른 필터링을 수행합니다.
- `DateTime.TryParseExact(segment, "yyyyMMdd")`로 유효한 날짜인지 최종 검증합니다.
- **무효한 날짜**(예: `20261345`)는 무시되고 오늘 날짜가 추가됩니다.

### 이동(Move) 경로 구조

**라인 구분 없음**

- **날짜 없음**: `<basePath>/<오늘날짜>/<subject>/<with_or_without_NIR>/...`
- **날짜 있음**: `<basePath>/.../<yyyyMMdd>/.../<subject>/<with_or_without_NIR>/...` (날짜 추가 없음)

**예시**:
```
# basePath에 날짜 없음
C:/Data/Output → C:/Data/Output/20250117/TestSubject/with NIR/일반

# basePath에 날짜 포함
C:/Data/20260107/Output → C:/Data/20260107/Output/TestSubject/with NIR/일반
```

### 삭제(Quarantine) 경로 구조

**라인 구분 포함**: `Line{N}/subject` 구조

- **날짜 없음**: `<basePath>/<오늘날짜>/Line{N}/<subject>/<role>[/folderName]`
- **날짜 있음**: `<basePath>/.../<yyyyMMdd>/.../Line{N}/<subject>/<role>[/folderName]` (날짜 추가 없음)

**예시**:
```
# basePath에 날짜 없음
C:/Data/Quarantine → C:/Data/Quarantine/20250117/Line1/TestSubject/일반1

# basePath에 날짜 포함
C:/Data/20260107/Quarantine → C:/Data/20260107/Quarantine/Line1/TestSubject/일반1
```

## 사용자 설정 가이드

### 경로 설정 시

**경로에 날짜를 포함할지 여부는 선택 가능합니다:**

1. **날짜 포함 경로** (권장)
   - 예: `D:/Data/20260107/Output`
   - 장점: 날짜별로 명확하게 구분 가능
   - 시스템이 자동으로 날짜를 추가하지 않음

2. **날짜 없는 경로**
   - 예: `D:/Data/Output`
   - 장점: 설정이 간단함
   - 시스템이 자동으로 오늘 날짜를 추가함

### 주의사항

- 경로에 **유효한 날짜**(예: `20260107`)가 포함되어 있으면 자동 추가되지 않습니다.
- 경로에 **무효한 날짜**(예: `20261345`)가 포함되어 있어도 유효하지 않으므로 오늘 날짜가 추가됩니다.
- 경로 중간에 날짜가 있어도 감지됩니다 (예: `C:/Data/20260107/Output/Backup`).


#### `EnsureDateRoot(string basePath)`
경로에 날짜가 없으면 오늘 날짜를 추가합니다.

```csharp
private static string EnsureDateRoot(string basePath)
{
    if (HasValidDateSegment(basePath))
        return basePath;
    
    var today = DateTime.Now.ToString("yyyyMMdd");
    return Path.Combine(basePath, today);
}
```

## 테스트 케이스

다음 시나리오들이 테스트를 통해 검증되었습니다:

1. **날짜 없음**: `C:/Data/Output` → 오늘 날짜 추가
2. **날짜 중간 포함**: `C:/Data/20260107/Output/Backup` → 날짜 존재, 추가 안 함
3. **무효 날짜**: `C:/Data/20261345/Output` → 무효 날짜 무시, 오늘 날짜 추가
4. **여러 날짜**: `C:/Data/20260101/Output/20260107/Backup` → 유효 날짜 존재, 추가 안 함
