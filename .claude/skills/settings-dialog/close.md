# 설정 대화상자 닫기 (settings-dialog:close)

## 설명
취소 버튼을 클릭하여 SettingsDialog를 닫습니다.

## CLI 명령
```bash
ui_automation.exe settings-dialog close
```

## 사용 예시
```bash
/settings-dialog:close
```
