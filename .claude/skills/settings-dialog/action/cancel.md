# 취소 (settings-dialog:action:cancel)

## 설명
취소 버튼을 클릭합니다 (변경 사항 폐기, 대화상자 닫기).

## CLI 명령
```bash
ui_automation.exe settings-dialog action cancel
```

## 사용 예시
```bash
/settings-dialog:action:cancel
```
