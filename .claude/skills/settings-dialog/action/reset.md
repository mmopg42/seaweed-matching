# 재설정 (settings-dialog:action:reset)

## 설명
재설정/기본값 버튼을 클릭합니다 (기본값으로 재설정, 대화상자 열림 유지).

## CLI 명령
```bash
ui_automation.exe settings-dialog action reset
```

## 사용 예시
```bash
/settings-dialog:action:reset
```
