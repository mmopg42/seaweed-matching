# 설정 대화상자 열기 (settings-dialog:open)

## 설명
설정 버튼을 클릭하여 SettingsDialog를 엽니다.

## CLI 명령
```bash
ui_automation.exe settings-dialog open
```

## 사용 예시
```bash
/settings-dialog:open
```
