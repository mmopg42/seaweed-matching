# Milestone v1.0: ChronoView UI Automation

**Status:** ✅ SHIPPED 2026-01-18
**Phases:** 1-10
**Total Plans:** 28

## Overview

FlaUI.UIA3 기반으로 ChronoView WPF 데스크톱 애플리케이션을 자동화하는 스킬 세트와 테스트 에이전트를 개발합니다. UI 요소 식별/조작 인프라부터 시작하여 점진적으로 모든 주요 기능을 자동화하고, 최종적으로는 Agent가 호출 가능한 CLI 인터페이스와 테스트 에이전트를 구현합니다.

## Milestone Summary

### Key Decisions

**Architecture:**
- FlaUI.UIA3 5.0.0 with net10.0-windows target for Windows automation
- System.CommandLine 2.0.0-beta4 for CLI interface
- Python subprocess-based test agent (language-agnostic approach)
- Pydantic for JSON output validation
- Dedicated controller classes (ChronoWindowFinder, ChronoToolbarController, ChronoDataPanelReader, ChronoWorkflowController, ChronoSettingsController, ChronoFileOperationsController)

**CLI Standardization:**
- Exit code constants pattern (SUCCESS=0, ERROR=1, NOT_FOUND=2, TIMEOUT=3, INVALID_ARGUMENT=4)
- JSON output wrapper: { success, data: {...} } or { success, error, errorCode }
- Global --quiet/--verbose options for agent control
- PrintOutput/PrintError helpers respecting quiet mode

**Test Infrastructure:**
- pytest with HTML reports (pytest-html)
- Test markers: destructive, slow, order
- Session-scoped CLI instance fixture
- Skip conditions for data-dependent tests

### Tech Stack

- **C# (.NET 10)**: FlaUI.UIA3 5.0.0, System.CommandLine 2.0.0-beta4
- **Python 3**: pytest>=7.0.0, pytest-html>=3.0.0, pydantic>=2.0.0

### Key Features Delivered

**CLI Commands (30+):**
- `test connectivity`, `test inspect`
- `windows find`, `windows list`
- `toolbar click`, `toolbar start`, `toolbar stop`, `toolbar settings`, `toolbar refresh`
- `stats get`, `datagrid get-row-count`, `datagrid export`
- `workflow inspect`, `workflow start-camera`, `workflow stop-camera`, `workflow set-path`
- `settings open`, `settings close`, `settings set-path`, `settings set-checkbox`
- `logs get`, `logs tail`, `logs filter`, `logs search`
- `file-ops select`, `file-ops move`, `file-ops delete`, `file-ops verify`
- `scenario start-monitoring`, `scenario configure-paths`
- `batch move-by-groupid`, `batch delete-by-groupid`

**Test Coverage (75+ tests):**
- Connectivity and smoke tests
- DataGrid access (non-destructive)
- Start/stop monitoring workflows
- Button state verification
- Camera launch operations
- Settings dialog navigation
- Log retrieval and filtering
- File operations (select, move, delete)
- Batch operations
- Post-operation verification
