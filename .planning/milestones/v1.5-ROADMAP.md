# Milestone v1.5: CLI Skill Encapsulation

**Status:** ✅ SHIPPED 2026-01-22
**Phases:** 28-32
**Total Plans:** 10

## Overview

Milestone v1.5 implements a skill abstraction layer that separates intent (orchestrator) from implementation (executor). AI agents use semantic skill names for test automation instead of constructing CLI commands directly. This creates a clean architectural boundary: orchestrators define WHAT to test (intent), executors handle HOW to execute it (implementation).

**Key Achievement:** 92 CLI commands mapped to semantic skill names across 13 categories, with standardized JSON responses, dry-run validation, and complete documentation.

## Milestone Summary

**Decimal Phases:**

None (all phases were sequential)

**Key Decisions:**

- 13 categories aligned with CLI command structure: APP, BATCH, CONSOLE_LOGS, DATA_PANEL, FILE_OPS, LOGS, SETTINGS_DIALOG, SETUP, TEST, TOOLBAR, UTILITY, WINDOWS, WORKFLOW
- UPPER_SNAKE_CASE naming convention for skill IDs (CATEGORY_ACTION format)
- TypeScript interface schemas for type safety
- Record types for immutability and concise syntax
- JsonNamingPolicy.CamelCase for consistent property naming
- ISO 8601 timestamps in 'o' format for all responses
- PrintLegacy() temporary helper for gradual migration
- Levenshtein distance threshold of 3 for finding similar skill names
- Category-first matching (by underscore prefix) before string similarity search
- DryRunResponse uses dryRun: true to distinguish validation from execution

**Issues Resolved:**

- Zero behavioral regressions - all CLI commands verified working after migration
- Build errors with JsonPropertyNameAttribute fixed by removing attributes and using JsonNamingPolicy
- SettingsCommands.cs duplicate closing brace fixed
- Missing System.Text.Json using statement added to DataPanelCommands

**Issues Deferred:**

None.

**Technical Debt Incurred:**

- SkillMapping dictionary in DryRunHandler.cs duplicates test-executor-skills.md (consider auto-generating at build time)
- TypeScript Interface Extraction: DryRunResponse TypeScript interface in test-executor.md could be extracted to shared types file
