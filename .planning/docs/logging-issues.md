# Logging Issues - 테스트를 위한 개선 필요

## 이슈: 콘솔 로그 실시간 확인 불가

### 현재 상황
- **콘솔 로그 파일**이 실행 중인 프로세스에 의해 잠겨 있어 읽기 불가
- UI 자동화 테스트 시 특정 액션 후 로그 검증 필요
- 현재는 LogPanel(UI용)만 읽을 수 있고, 개발자용 콘솔 로그는 확인 불가

### 영향
| 테스트 시나리오 | 필요한 검증 | 현재 상태 |
|----------------|-------------|----------|
| 버튼 클릭 → 이벤트 발생 확인 | 콘솔 로그에서 "Command executed" 확인 | ❌ 불가 |
| 카메라 시작 실패 디버깅 | 콘솔 로그 스택 트레이스 확인 | ❌ 불가 |
| 파일 감지 동작 확인 | 콘솔 로그에서 "File detected" 확인 | ❌ 불가 |

### 필요한 기능
1. **콘솔 로그 파일 읽기** (읽기 공유 모드)
2. **실시간 로그 모니터링** (tail -f)
3. **CLI 명령 추가**
   ```bash
   ui_automation console-logs tail <n>     # 최근 n줄
   ui_automation console-logs search <text> # 텍스트 검색
   ui_automation console-logs follow         # 실시간 추적
   ```

### 해결 방법
- C# `FileStream` with `FileShare.ReadWrite` 모드 사용
- 또는 로그 파일을 복사해서 읽기
- 또는 로그를 표준 출력으로 리다이렉션하고 파이프로 읽기

### 우선순위
**P0 - 테스트 에이전트 구현 전 반드시 필요**
