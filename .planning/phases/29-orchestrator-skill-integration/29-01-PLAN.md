```markdown
## Skill-Based Delegation Format

When delegating to test-executor, use the skill format:

**Minimal format:**
```
Skill(skill='SKILL_NAME')
```

**Full format:**
```
Skill(
  skill='SKILL_NAME',
  args={'param1': 'value1', 'param2': 'value2'},
  description='What this action accomplishes in the test context',
  timeout=30000
)
```

**Examples:**

1. Launch application:
```
Skill(skill='APP_LAUNCH', description='Launch ChronoView for testing')
```

2. Start monitoring:
```
Skill(skill='TOOLBAR_START', description='Begin file monitoring workflow')
```

3. Select and move rows:
```
Skill(
  skill='FILE_OPS_MOVE_ROWS',
  args={'rows': [0, 1, 2]},
  description='Move first 3 file groups to output folder'
)
```

4. Read DataGrid data:
```
Skill(
  skill='DATA_PANEL_DATA',
  description='Capture current file group data for verification'
)
```

5. Get camera states:
```
Skill(
  skill='WORKFLOW_CAMERA_STATES',
  description='Verify all cameras are in expected state'
)
```
```
