**2. `setup camera-states` command:**
- Uses `ChronoSetupWindowController.GetCameraStates()` method
- Returns Dictionary<string, string> with keys: "general", "nir1", "nir2"
- Values are button states (e.g., "Enabled", "Disabled")
- Usage: `setup camera-states --json`
- Required by CLI-01

Implementation pattern (reference existing code in SetupCommands.cs):
```csharp
var commandName = new Command("command-name", "Description");
commandName.AddOption(jsonOption);
commandName.SetHandler((json) =>
{
    using var controller = new ChronoSetupWindowController();
    var result = controller.MethodName();

    if (json)
    {
        PrintJsonOutput(new { success = result, ... });
    }
    else
    {
        Console.WriteLine($"[command-name] {(result ? "Success" : "Failed")}");
    }
    Environment.Exit(result ? EXIT_SUCCESS : EXIT_ERROR);
}, jsonOption);
setupCommand.AddCommand(commandName);
```

Note: Unlike workflow namespace commands, these setup commands specifically target the SetupWindow context, which is the active window during initial application setup.
