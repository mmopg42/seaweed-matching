  <action>
Modify SetupCommands.cs to replace all Environment.Exit() calls with return statements.

Changes needed:
1. Remove local exit code constants (lines 16-21): EXIT_SUCCESS, EXIT_ERROR, EXIT_NOT_FOUND, EXIT_TIMEOUT, EXIT_INVALID_ARGUMENT
2. Add `using static UiAutomation.Commands.ExitCodes;` at top to use constants directly
3. Change all SetHandler lambdas to return int instead of calling Environment.Exit()

Pattern example for verifyConfigCommand (lines 64-94):
OLD:
```csharp
verifyConfigCommand.SetHandler((configPath, openSettings, strict, json) =>
{
    // ... handler logic ...
    Environment.Exit(exitCode);
}, ...);
```

NEW:
```csharp
verifyConfigCommand.SetHandler((configPath, openSettings, strict, json) =>
{
    try
    {
        // ... handler logic ...
        return exitCode;  // Return instead of Environment.Exit
    }
    catch (Exception ex)
    {
        Console.Error.WriteLine($"[setup verify-config] Error: {ex.Message}");
        return ERROR;
    }
}, ...);
```
