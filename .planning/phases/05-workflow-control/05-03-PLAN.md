<task type="auto">
  <name>Task 1: Add path finding methods to ChronoWorkflowController</name>
  <files>skills_scripts/ui_automation/ChronoWorkflowController.cs</files>
  <action>
    Add path TextBox finding and reading methods to ChronoWorkflowController:

    Methods to implement:
    1. FindPathTextBox(AutomationElement? workflowPanel, string labelText) - finds TextBox by its associated Label
       - Searches for Text (ControlType.Text) containing labelText
       - Finds sibling or parent-descendant TextBox (ControlType.Edit)
       - Returns TextBox AutomationElement?

    2. GetTextBoxValue(AutomationElement? textBox) - reads current text from Edit control
       - Uses ValuePattern if available (textPattern.Value)
       - Fallback to textBox.Name if ValuePattern not supported
       - Returns string value or empty string if error

    3. SetTextBoxValue(AutomationElement? textBox, string value) - sets text in Edit control
       - Uses ValuePattern.SetValue(value)
       - Returns true if success, false otherwise
       - Logs set operation with old and new values

    4. GetLine1Paths() - reads all Line 1 paths
       - Returns Dictionary<string, string> with keys: SampleName, MoveNir, MoveAllData
       - Uses FindPathTextBox with labels from XAML (Strings resources)

    5. GetLine2Paths() - reads all Line 2 paths
       - Similar to Line1 but for Line 2 labels

    6. SetLine1Path(string pathType, string value) - sets specific Line 1 path
       - pathType: "SampleName", "MoveNir", "MoveAllData"
       - Finds corresponding TextBox and sets value

    7. SetLine2Path(string pathType, string value) - sets specific Line 2 path
       - Similar to SetLine1Path

    8. GetAllPaths() - returns all paths from both lines
       - Returns nested Dictionary or dedicated class/record

    Note: TextBox controls in WPF appear as ControlType.Edit in UI Automation.
    Label-TextBox association: Label is ControlType.Text, TextBox is ControlType.Edit,
    they share a parent StackPanel or Grid.
  </action>
  <verify>Build succeeds, methods compile without errors</verify>
  <done>Path finding and reading methods exist in ChronoWorkflowController</done>
</task>
