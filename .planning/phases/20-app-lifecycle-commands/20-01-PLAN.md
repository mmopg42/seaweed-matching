   - Wrap in Task.Run for async non-blocking launch

   - Output: ProcessId if launched, 0 if failed

   - Handle InvalidOperationException for already-exited processes gracefully
   - Output: Count of processes killed
   - Exit code: 0 if any killed, 2 if none found

   - Call stop logic first, await Task.Delay(500) for cleanup
   - Then launch new instance
   - Output: Processes stopped + new ProcessId
   - Exit code: 0 on success, 1 on failure

   - Use Process.GetProcessesByName("ChronoView")
   - Output: isRunning (bool), processCount (int), processIds (int[]), mainWindowTitles (string[])
   - Support --json option for structured output
   - Exit code: 0 if running, 2 if not running
