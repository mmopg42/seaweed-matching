       ```python
           state = {
               "status": status,
               "progress": round(progress, 1),
               "items_created": items_created,
               "simulation_id": simulation_id,
               "last_activity": datetime.now().isoformat()
           }
           try:
               with open(self._get_state_file_path(), 'w') as f:
                   json.dump(state, f, indent=2)
           except Exception as e:
               print(f"[Warning] Failed to write state file: {e}")
       ```

    3. _load_state() - Reads state from file, returns None if not exists
       ```python
       def _load_state(self):
           state_path = self._get_state_file_path()
           if not os.path.exists(state_path):
               return None
           try:
               with open(state_path, 'r') as f:
                   return json.load(f)
           except Exception:
               return None
       ```

    4. get_status() - Returns current status (reads from state file)
       ```python
       def get_status(self):
           state = self._load_state()
           if state is None:
               return {
                   "status": "idle",
                   "progress": 0,
                   "items_created": 0,
                   "simulation_id": None,
                   "last_activity": None
               }
           return state
       ```
