  <action>Add "settings checkbox" and "settings action" subcommands:

**Checkbox commands:**
- "settings checkbox get <name>": Gets CheckBox state (true/false)
- "settings checkbox set <name> <true|false>": Sets CheckBox state
- "settings checkbox list": Lists all CheckBox states in Advanced tab as JSON

**Action commands:**
- "settings action save": Clicks OK/Save button, waits for dialog close
- "settings action apply": Clicks Apply button (dialog stays open)
- "settings action cancel": Clicks Cancel button, waits for dialog close
- "settings action reset": Clicks Reset/Defaults button

Supported checkbox names (use underscores for spaces):
- use_folder_suffix, use_camera_subfolder_normal, use_camera_subfolder_normal2
- use_disk_cache, use_line_specific_group_id
- enable_nir_graph, show_tooltips
- compare_to_reference_camera
