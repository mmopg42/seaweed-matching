**Phase 20 delivered these new commands:**
- `app launch` - Launch ChronoView using dotnet run (non-blocking)
- `app stop` - Kill all ChronoView processes
- `app restart` - Stop all processes, wait 500ms, then launch
- `app status` - Check if ChronoView is running with process details
- All commands support --json for programmatic output

**Exit codes:** 0=success, 1=error, 2=not_found, 3=timeout
