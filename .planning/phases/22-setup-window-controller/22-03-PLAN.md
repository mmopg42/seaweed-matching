<task id="7" name="Implement setup verify-config command">
Add command to SetupCommands:
- `setup verify-config [--config-path PATH]`
- Reads simulator config
- Opens ChronoView SettingsDialog if needed
- Compares paths
- Outputs JSON result

Usage:
```
setup verify-config --config-path "task_helper/data_test/simulator_config.json" --json
```

Output format:
```json
{
  "success": true,
  "data": {
    "all_match": true,
    "matched": ["source_line1", "target_base"],
    "mismatches": [],
    "missing": [],
    "details": {
      "source_line1": {
        "simulator": "/path/to/line1",
        "chronoview": "/path/to/line1",
        "match": true
      }
    }
  }
}
```
</task>
