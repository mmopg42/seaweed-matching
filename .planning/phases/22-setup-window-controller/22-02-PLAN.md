## Objective

Create `SetupCommands` CLI handler and implement the complete setup workflow that:
1. Launches cameras in sequence (General → NIR1 → NIR2)
2. Optionally opens SettingsDialog for verification
3. Clicks Start button to transition to MainWindow
4. Waits for MainWindow to appear

## Tasks

<tasks>
<task id="1" name="Create SetupCommands class structure">
Create new file `skills_scripts/ui_automation/Commands/SetupCommands.cs` with:
- Class implementing `ICommandHandler`
- Exit code constants (SUCCESS=0, ERROR=1, NOT_FOUND=2, TIMEOUT=3)
- Private helper methods for JSON output
- RegisterCommands method for CLI registration

Reference `WindowsCommands.cs:11-27` for pattern.
</task>

<task id="2" name="Implement setup open-settings command">
Create command `setup open-settings`:
- Finds SetupWindow using ChronoSetupWindowController
- Clicks Settings button
- Waits for SettingsDialog to open
- Returns success/failure with optional JSON output

Usage: `setup open-settings [--json]`
</task>

<task id="3" name="Implement setup click-camera commands">
Create commands for individual camera buttons:
- `setup camera-general` - click General camera button
- `setup camera-nir1` - click NIR1 button
- `setup camera-nir2` - click NIR2 button

Each command:
- Accepts --json flag for programmatic output
- Uses ChronoSetupWindowController methods
- Returns success/failure status
</task>

<task id="4" name="Implement setup toggle-nir-filtering command">
Create command `setup toggle-nir-filtering`:
- Optional --state parameter (on/off)
- Toggles NIR filtering if no state specified
- Sets to specific state if provided
- Reports final state

Usage: `setup toggle-nir-filtering [--state on|off] [--json]`
</task>

<task id="5" name="Implement setup camera-states command">
Create command `setup camera-states`:
- Returns JSON with camera button states
- Shows enabled/disabled status for each camera
- Useful for test verification

Usage: `setup camera-states [--json]`

Output format:
```json
{
  "success": true,
  "data": {
    "general": true,
    "nir1": true,
    "nir2": false
  }
}
```
</task>

<task id="6" name="Implement setup start-monitoring command">
Create command `setup start-monitoring`:
- Clicks Start button (SetupStartButton)
- Waits for MainWindow to appear
- Verifies transition completed
- Returns success when MainWindow is ready

Usage: `setup start-monitoring [--json] [--timeout-ms 10000]`
</task>

<task id="7" name="Implement setup complete-full command">
Create command `setup complete-full`:
- Executes full setup workflow:
  1. Click General camera
  2. Wait 500ms
  3. Click NIR1 camera
  4. Wait 500ms
  5. Click NIR2 camera
  6. Wait 500ms
  7. Optional: toggle NIR filtering if needed
  8. Click Start button
  9. Wait for MainWindow (10s timeout)
- Returns detailed status of each step

Usage: `setup complete-full [--json] [--skip-nir-toggle] [--timeout-ms 10000]`

Output format:
```json
{
  "success": true,
  "data": {
    "steps": {
      "general_camera": true,
      "nir1_camera": true,
      "nir2_camera": true,
      "start_button": true,
      "mainwindow_ready": true
    },
    "duration_ms": 2500
  }
}
```
</task>
