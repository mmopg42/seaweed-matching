**Wave:** 1
**Depends On:** None
**Files Modified:**

## Objective

Create `ChronoSetupWindowController` class that provides high-level API for SetupWindow automation. This class follows the same pattern as `ChronoSettingsController` and encapsulates all SetupWindow interaction logic.

---

## Context

From research findings:
- SetupWindow has clear AutomationId values for all buttons
- `ChronoWindowFinder.FindSetupWindow()` already exists
- `ChronoSettingsController` has SetupWindow-aware button detection
- Target size: ~400 lines (similar to ChronoSettingsController at ~1650 lines but focused on fewer elements)

## Tasks

<tasks>
<task id="1" name="Create ChronoSetupWindowController class structure">
Create new file `skills_scripts/ui_automation/ChronoSetupWindowController.cs` with:
- Class implementing `IDisposable` pattern
- Constructor accepting `UIA3Automation` (with overload creating its own)
- Private fields: `_automation`, `_windowFinder`, `_const` poll interval
- XML documentation comments for class summary

Reference `ChronoSettingsController.cs:38-60` for pattern.
</task>

<task id="2" name="Implement FindSetupWindow method">
Add method to find and return SetupWindow:
- Reuse `ChronoWindowFinder.FindSetupWindow()`
- Return null if not found
- Log results via Console.WriteLine
- Follow pattern from `ChronoSettingsController.FindMainWindow()`

Method signature: `public Window? FindSetupWindow()`
</task>

<task id="3" name="Implement ClickSettingsButton method">
Add method to click SetupSettingsButton:
- Find SetupWindow first (parameter optional, will find if null)
- Find button by AutomationId "SetupSettingsButton"
- Use InvokePattern for clicking
- Return true if successful, false otherwise

Method signature: `public bool ClickSettingsButton(Window? setupWindow = null)`
</task>

<task id="4" name="Implement camera launch button methods">
Add three methods for camera buttons:
- `ClickGeneralCamera()` - AutomationId "SetupGeneralCameraButton"
- `ClickNir1()` - AutomationId "SetupNir1CameraButton"
- `ClickNir2()` - AutomationId "SetupNir2CameraButton"

Each method:
- Finds SetupWindow if not provided
- Finds button by AutomationId
- Uses InvokePattern.Click()
- Returns success/failure boolean
- Logs action and result
</task>

<task id="5" name="Implement ToggleNirFiltering method">
Add method to toggle NIR filtering:
- Find button by AutomationId "SetupNirFilteringButton"
- Read current state from button text ("NIR 필터: ON/OFF")
- Click to toggle if needed
- Optional: targetState parameter to only click if current != target

Method signature: `public bool ToggleNirFiltering(bool? targetState = null, Window? setupWindow = null)`
</task>

<task id="6" name="Implement ClickStartButton method">
Add method to click Start Monitoring button:
- AutomationId "SetupStartButton"
- This triggers transition to MainWindow
- Return true if click successful

Method signature: `public bool ClickStartButton(Window? setupWindow = null)`
</task>

<task id="7" name="Implement CloseWindow method">
Add method to close SetupWindow:
- AutomationId "SetupCloseButton"
- Use InvokePattern or window.Close()
- Wait for window to close after clicking

Method signature: `public bool CloseWindow(Window? setupWindow = null, int timeoutMs = 5000)`
</task>

<task id="8" name="Implement WaitForMainWindow method">
Add method to wait for MainWindow after Start button:
- Uses `ChronoWindowFinder.WaitForWindow("ChronoView Pro")`
- Optional: also verify SetupWindow closed
- Return MainWindow or null on timeout

Method signature: `public Window? WaitForMainWindow(int timeoutMs = 10000)`
</task>

<task id="9" name="Implement GetCameraStates method">
Add method to read camera button states:
- Returns dictionary with general, nir1, nir2 states
- Checks if each button exists and is enabled
- Useful for "setup camera-states" command

Method signature: `public Dictionary<string, bool> GetCameraStates(Window? setupWindow = null)`
</task>

<task id="10" name="Implement helper methods">
Add private helper methods:
- `FindButtonById(Window, string automationId)` - find by AutomationId
- `ClickButton(AutomationElement)` - generic click using InvokePattern
- `Dispose()` - cleanup automation resources

Follow pattern from `ChronoSettingsController.cs:394-422`
</task>
</tasks>
