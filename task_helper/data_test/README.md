# Data Simulator - Timestamp-based File Copy Tool

실제 데이터 생성 타이밍을 재현하여 ChronoView 모니터링을 테스트하기 위한 시뮬레이터입니다.

## 기능

- 소스 폴더의 모든 파일/폴더에서 타임스탬프 추출
- 추출된 타임스탬프 순서대로 정렬
- 시작 후 5초 대기 후 실제 시간차만큼 지연하며 타겟 폴더로 복사
- 폴더 구조 유지
- GUI로 간편한 조작

## 지원하는 데이터 형식

### NIR 파일 (`nir/`)
- 형식: `run_120251201T140542.spc`, `run_120251201T140542A.txt`
- 타임스탬프 위치: `T` 다음 6자리 (`HHMMSS`)

### Normal 폴더 (`normal/`)
- 형식: `C251201T140543_0/`
- 타임스탬프 위치: `T` 다음 6자리 (`HHMMSS`)

### Camera 파일 (`cam1/`, `cam2/`, `cam3/`)
- 형식: `20251201_140548_897.bmp`
- 타임스탬프 위치: 첫 번째 `_` 다음 6자리 (`HHMMSS`)

## 사용 방법

### 1. 실행
```bash
python data_simulator.py
```

### 2. 설정
1. **Source Folder**: 원본 데이터 폴더 (기본값: `Z:\윤태경\seaweed\program\data\2025_A046`)
2. **Target Folder**: 복사할 대상 폴더 (Browse 버튼으로 선택)

### 3. 시뮬레이션 시작
1. `Start Simulation` 버튼 클릭
2. 5초 카운트다운 후 시작
3. 각 파일/폴더가 타임스탬프 순서대로 복사됨

### 4. 초기화
- `Reset Target Folder` 버튼: 타겟 폴더의 모든 내용 삭제 (재테스트용)
- `Stop` 버튼: 실행 중인 시뮬레이션 중지

## 동작 원리

1. 소스 폴더에서 모든 파일/폴더 스캔
2. 각 항목에서 타임스탬프 추출
3. 타임스탬프 기준으로 정렬
4. 첫 번째 항목의 타임스탬프를 t0로 설정
5. 각 항목을 `(항목_타임스탬프 - t0)` 만큼 지연 후 복사

### 예시
```
run_120251201T140542.spc  -> 14:05:42 (t0 = 0초)
C251201T140543_0/         -> 14:05:43 (t0 + 1초 후 복사)
20251201_140548_897.bmp   -> 14:05:48 (t0 + 6초 후 복사)
```

## 요구사항

- Python 3.7+
- tkinter (Python 기본 라이브러리)
- 표준 라이브러리만 사용 (추가 설치 불필요)

## 테스트 시나리오

1. ChronoView 실행 및 모니터링 시작
2. Data Simulator에서 타겟 폴더를 ChronoView의 모니터링 폴더로 설정
3. `Start Simulation` 클릭
4. ChronoView에서 실시간으로 파일 그룹이 생성되는 것 확인
5. 테스트 완료 후 `Reset Target Folder`로 초기화
6. 필요시 재테스트

## 주의사항

- 타겟 폴더는 반드시 지정해야 함
- Reset 기능은 타겟 폴더의 **모든 내용을 삭제**하므로 주의
- 시뮬레이션 중 Stop 버튼으로 언제든지 중지 가능
- 복사는 원본을 유지하므로 여러 번 재시도 가능
